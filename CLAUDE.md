# Ponytail Rules

Before writing code:

1. Does this need to exist?
2. Can the standard library solve it?
3. Does the platform already provide it?
4. Can an existing dependency solve it?
5. Can it be done in one line?
6. Only then write the minimum code that works.

Avoid:

- unnecessary abstractions
- unnecessary dependencies
- premature optimization
- over-engineering

Never compromise:

- security
- accessibility
- input validation
- data integrity
